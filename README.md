# pi_benchmark
This will benchmark your Raspberry Pi's CPU, RAM, etc.

Instructions on how to install:
-
•Execute this command in your Pi's terminal:
```
nano benchmark-pi-comprehensive.sh
```
•Copy and paste the benchmark-pi-comprehensive.sh file into your terminal

•Press **ctrl + X** then **Y** and then **Enter**

•Execute this:
```
chmod +x benchmark-pi-comprehensive.sh
```
•Run the Benchmark:
```
./benchmark-pi-comprehensive.sh
```
